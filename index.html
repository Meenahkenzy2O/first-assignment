Welcome to My First Assignment

This project demonstrates the creation of semantic HTML pages with proper accessibility features. The assignment includes:

  • Semantic HTML structure with appropriate tags (<header>, <nav>, <main>, <section>, <footer>)
  • Accessible form design following WCAG guidelines
  • Global navigation between pages at the top
  • Responsive footer with contact and copyright information
  • Keyboard navigation and screen reader support
  • Proper heading hierarchy and label associations

Project Details

This assignment focuses on creating well-structured, accessible web pages that can be easily imported into CodePen or any other web environment. Both pages maintain consistent navigation and branding throughout.

Key features implemented:

  • Semantic HTML: Using proper HTML5 elements for content structure
  • Accessibility (a11y): ARIA labels, skip links, focus states, and color contrast
  • Responsive Design: Mobile-friendly layouts using CSS media queries
  • Navigation: Consistent header navigation on both pages
